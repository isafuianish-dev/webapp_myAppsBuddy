# My Apps Buddy

Your home base for the whole Buddy collection — one page linking out to every tool in the set.

My Apps Buddy is the launcher page for a small collection of single-purpose browser tools, built one at a time. Everything in the collection runs entirely client-side and stays on your device — there's no backend and no accounts anywhere. Open this page and you'll see every available app laid out as a grid of tiles you can jump into with a single click.

## Features

- **Grouped tiles.** Apps are organized into two sections: **Apps** (productivity and utility tools like JSON formatting, Kanban boards, expense trackers, note-taking, habit tracking, and more) and **Games** (Minesweeper, Ludo, Memory Match, Sudoku, Snake, and more).
- **Compact grid layout.** Each app gets a small square tile showing its index number, a two-letter symbol (like "Js" for JSON or "Kb" for Kanban), and its short name.
- **Hover-to-expand tiles.** Hovering (or focusing) a tile smoothly expands it into a larger card that reveals the app's icon, full name, a one-line description of what it does, and an "Open" button — so you can preview what a tool is before clicking into it.
- **"New" ribbons.** Recently added apps are marked with a small "New" ribbon in the corner of their tile so they stand out from the rest of the grid.
- **"More soon" placeholders.** Each section ends with a dashed placeholder tile, signaling that more apps and games are on the way.
- **Made-with-love footer.** Clicking the heart icon in the footer triggers a small heart-burst animation with a "Thank you!" message.

## How to Use

1. Scroll through the **Apps** section for everyday tools, and the **Games** section for casual games.
2. Hover over (or tap, on touch devices) any tile to see its full name and a short description of what it does.
3. Click the tile — or the "Open" button that appears when it's expanded — to launch that app. It opens in the same tab, so use your browser's back button to return to this page.
4. Look out for tiles marked "New" if you want to check out the latest additions first.

## Customization

Click the gear icon in the top-right corner to open the Settings panel, which applies to this page's appearance:

- **Theme** — switch between Light and Dark mode using the sun/moon toggle.
- **Accent** — pick an accent color from the swatches to change the highlight color used across tiles, headings, and buttons.

Your theme and accent choices are remembered for the next time you visit.
